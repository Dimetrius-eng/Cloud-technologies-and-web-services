# Дисципліна: “Хмарні технології та сервіси”  
## Лабораторна робота №1. Дослідження хмарних сервісів моделі SaaS
### Мета: Ознайомлення з популярними хмарними сервісами моделі SaaS та їх дослідження та налаштування для вирішення прикладних завдань
---
### Завдання попередньої підготовки

<span>1. Підготуйте невеликий словник термінів (до 10 визначень) пов'язаних з поняттям SaaS. Візуалізуйте їх у вигляді інтелект-карти.</span>  
<span>2. Дайте відповіді на наступні питання:</span>  

<blockquote>

2.1. Використовуючи інтернет-джерела, дайте визначення. Порівняйте моделі SaaS з PaaS та IaaS.  

</blockquote>

* **IaaS (Infrastructure as a Service):** провайдер надає базові віртуальні сервери, мережі та сховища. Користувач повністю керує ОС, middleware та додатками (наприклад, *AWS EC2, Google Compute Engine*).
* **PaaS (Platform as a Service):** провайдер надає готову платформу та середовище для розробки й деплою (ОС, бази даних, runtime). Розробник керує лише кодом додатків (наприклад, *Google App Engine, Heroku*).
* **SaaS (Software as a Service):** провайдер надає повністю готове до використання програмне забезпечення в браузері. Користувач не керує інфраструктурою чи платформою (наприклад, *Google Docs, Figma, Trello*).

<blockquote>

2.2. Наведіть приклади 5 популярних на вашу думку SaaS-сервісів для роботи сучасного ІТ-спеціаліста. Вкажіть їх функціональність та переваги.  

</blockquote>

* **GitHub Codespaces (Cloud IDE):**
  * *Functionality:* Хмарне середовище розробки на базі VS Code.
  * *Advantages:* Повна конфігурація Dev Container, миттєвий запуск коду з будь-якого пристрою.
* **Figma (UI/UX Design &amp; Prototyping):**
  * *Functionality:* Векторний графічний редактор для проектування інтерфейсів.
  * *Advantages:* Колаборація дизайнерів і розробників в режимі реального часу, інспектування CSS-коду.
* **Notion (Knowledge Base &amp; Task Management):**
  * *Functionality:* Універсальний робочий простір для документування, баз знань і таск-трекінгу.
  * *Advantages:* Гнучкість баз даних, підтримка Markdown, зв’язування документів.
* **Google Colab (Data Science &amp; Machine Learning):**
  * *Functionality:* Jupyter Notebooks у хмарі з безкоштовним доступом до GPU/TPU.
  * *Advantages:* Ідеально для ML-моделей, аналізу даних та демонстрації Python-скриптів.
* **Postman Cloud (API Development &amp; Testing):**
  * *Functionality:* Платформа для розробки, тестування та документування REST API.
  * *Advantages:* Спільні колекції запитів для всієї IT-команди, автотести.

<blockquote>

2.3. Поясніть поняття "колаборація в реальному часі". Наведіть приклади, де її можна використати в SaaS-сервісах. 

</blockquote>

Це можливість одночасної роботи кількох користувачів над одним об’єктом (документом, макетом, дошкою завдань) через мережу з відображенням курсорів, коментарів та правок інших учасників у режимі реального часу.

* *Сфери використання:*
  * **Парне програмування** у Google Colab або GitHub Codespaces.
  * **Спільний UI/UX дизайн** та коригування прототипів у Figma.
  * **Планування спринтів** на Kanban-дошках Trello / Asana.

### Хід роботи

<span>1. Відкрийте браузер Google Chrome (або будь-який інший)</span>

<span>2. Розглянути та порівняти наступні хмарні сервіси. Пояснити чому їх можна віднести до моделі SaaS. Як ІТ-спеціалісти дані сервіси можуть використовувати у своїй професійній діяльності?</span> 

**1. Офісні та продуктивні інструменти:**  
* Google Workspace
* Microsoft 365
* Zoho Docs

Працюють у веб-браузері, дані зберігаються на серверах провайдерів, оновлення відбуваються автоматично без встановлення локальних дистрибутивів.
Використовують для написання технічних завдань (ТЗ), ведення документації проєкту, розрахунку кошторисів у таблицях та підготовки презентацій для замовників.

**2. Зберігання файлів і синхронізація:**  
* Dropbox (базовий тариф) 
* pCloud 
* Mega

Надають хмарний доступ до дискового простору за допомогою веб-інтерфейсу або легких клієнтів із автоматичним резервуванням даних на стороні провайдера.
Використовують для збереження дистрибутивів, резервного копіювання конфігурацій, обміну великими медіа-файлами та архівами з клієнтами.

**3. Спільна робота та управління проєктами:**  
* Trello 
* Asana 
* Notion

Готові онлайн-сервіси для координації задач, доступні з будь-якого пристрою без потреби налаштування власних баз даних.
Використовують для ведення розробки за методологіями Agile/Scrum, розподілу тасків між розробниками, відстеження дедлайнів (Gantt/Kanban).

**4. Комунікація та відеоконференції:**  
* Zoom
* Google Meet 
* Slack (free plan) 

Сервіси обробляють аудіо/відео потоки та повідомлення на власній хмарній інфраструктурі провайдера.
Використовують для проведення daily stand-up мітингів, демо-сесій для замовників, обговорення архітектурних рішень у текстових каналах.

**5. Графічний дизайн і редагування медіа:**  
* Canva
* Pixlr 
* Figma 

Складні векторні та растрові графічні обчислення виконуються в хмарі/браузері без навантаження на локальне відеоядро.
Використовують для створення wireframe-прототипів, проектування UI/UX систем, брендингу та підготовки графічних асетів для фронтенду.

**6. Хмарні середовища розробки (IDE):**  
* Replit
* Google Colab
* GitHub Codespaces

Надають повноцінні контейнеризовані середовища виконання коду без необхідності локального налаштування компіляторів чи інтерпретаторів.
Використовують для швидкого тестування фрагментів коду, Data Science аналітики, спільного навчання та віддаленої розробки з малопотужних пристроїв.
