2.1. Використовуючи інтернет-джерела, дайте визначення. Порівняйте моделі SaaS з PaaS та IaaS.

* **IaaS (Infrastructure as a Service):** провайдер надає базові віртуальні сервери, мережі та сховища. Користувач повністю керує ОС, middleware та додатками (наприклад, *AWS EC2, Google Compute Engine*).
* **PaaS (Platform as a Service):** провайдер надає готову платформу та середовище для розробки й деплою (ОС, бази даних, runtime). Розробник керує лише кодом додатків (наприклад, *Google App Engine, Heroku*).
* **SaaS (Software as a Service):** провайдер надає повністю готове до використання програмне забезпечення в браузері. Користувач не керує інфраструктурою чи платформою (наприклад, *Google Docs, Figma, Trello*).

<blockquote>

2.2. Наведіть приклади 5 популярних на вашу думку SaaS-сервісів для роботи сучасного ІТ-спеціаліста. Вкажіть їх функціональність та переваги.  

</blockquote>

* **GitHub Codespaces (Cloud IDE):**
  * *Functionality:* Хмарне середовище розробки на базі VS Code.
  * *Advantages:* Повна конфігурація Dev Container, миттєвий запуск коду з будь-якого пристрою.
* **Figma (UI/UX Design &amp; Prototyping):**
  * *Functionality:* Векторний графічний редактор для проектування інтерфейсів.
  * *Advantages:* Колаборація дизайнерів і розробників в режимі реального часу, інспектування CSS-коду.
* **Notion (Knowledge Base &amp; Task Management):**
  * *Functionality:* Універсальний робочий простір для документування, баз знань і таск-трекінгу.
  * *Advantages:* Гнучкість баз даних, підтримка Markdown, зв’язування документів.
* **Google Colab (Data Science &amp; Machine Learning):**
  * *Functionality:* Jupyter Notebooks у хмарі з безкоштовним доступом до GPU/TPU.
  * *Advantages:* Ідеально для ML-моделей, аналізу даних та демонстрації Python-скриптів.
* **Postman Cloud (API Development &amp; Testing):**
  * *Functionality:* Платформа для розробки, тестування та документування REST API.
  * *Advantages:* Спільні колекції запитів для всієї IT-команди, автотести.

</blockquote>

### Відповіді на контрольні питання

**<span>1. Порівняйте можливості збереження даних у Dropbox, Google Drive та OneDrive. Які функції резервного копіювання та безпеки вони надають?</span>**

* **Google Drive:** Інтеграція з Google Workspace, 15 ГБ безкоштовно. Захист через Двофакторну автентифікацію (2FA) та шифрування TLS/AES-256. Автоматичне версіонування документів.
* **Dropbox:** Найкраща технологія блокової синхронізації (LAN sync, Delta sync), 2 ГБ безкоштовно. Надає функцію *Dropbox Rewind* для відновлення стану акаунта при атаках ransomware.
* **OneDrive:** Глибока інтеграція з Windows 11 та MS 365. Безпечна зона *Personal Vault* з біометричним захистом.

**<span>2. Дослідіть онлайн-інструменти для управління проєктами: Trello та Asana. Які є спільні та відмінні риси?</span>**

* **Спільне:** Хмарні трекери задач, підтримка методів Agile, додавання файлів, коментарів та виконавців.
* **Відмінності:** Trello фокусується на простих Kanban-дошках для невеликих команд. Asana пропонує потужний інструментарій для великих проєктів (Timeline/Gantt, діаграми завантаженості ресурсів, порфоліо).

**<span>3. Дослідіть можливості Google Apps Script для автоматизації роботи в Google Документах та Таблицях. Наведіть приклади його використання.</span>**

Це мова сценаріїв на базі JavaScript для автоматизації сервісів Google.

* *Приклади використання:*
  * Автоматична генерація pdf-звітів на основі даних із Google Sheets.
  * Надсилання email-сповіщень клієнтам при зміні статусу завдання в таблиці.
  * Парсинг даних з зовнішніх REST API безпосередньо в Google Docs.

**<span>4. Порівняйте можливості Google Colab та Replit для онлайн-розробки коду. В яких випадках один сервіс буде кращим за інший?</span>**

* **Google Colab:** Ідеальний для Data Science, ML та обчислень на Python завдяки безкоштовному наданню потужностей GPU/TPU.
* **Replit:** Повноцінна багатомовна Cloud IDE (Python, Node.js, C++, Go) з підтримкою вебу, терміналу bash, розгортанням веб-серверів та постійним хостингом.

**<span>5. Чи можна онлайн-конструктори сайтів віднести до хмарних SaaS-сервісів? Поясніть чому та наведіть приклади.</span>**

**Так, повністю.** Вони працюють за моделлю SaaS, оскільки надають доступ до програмного середовища конструювання через веб-браузер. Хостинг, бази даних, оновлення движка та безпека повністю забезпечуються провайдером без доступу користувача до нижньорівневого заліза. Приклади: *Wix, Webflow, Squarespace, Shopify*.

### Висновки

Під час виконання лабораторної роботи було детально досліджені та практично випробувані хмарні сервіси моделі SaaS (Software as a Service). Було засвоєно навички створення єдиного командного простору для управління IT-проєктом: від написання ТЗ у Google Docs та розрахунку бюджету в Google Sheets до побудови UI-макетів у Figma, таск-трекінгу в Trello та написання коду в Google Colab. Отримані знання доводять, що сучасні SaaS-платформи дозволяють повністю забезпечити цикл розробки ПЗ без купівлі та налаштування локальної інфраструктури.
