<span>4. Дослідіть перспективні напрямки розвитку хмарних провайдерів AWS, Azure та GCP. Опишіть які інноваційні рішення у них були реалізовані за останні роки.</span>

<blockquote>

* **Amazon Web Services (AWS):**
  * **Генеративний ШІ та платформенні сервіси:** Запуск платформи **AWS Bedrock**, що надає доступ до провідних базових моделей штучного інтелекту (Anthropic Claude, Meta Llama, Amazon Titan) через єдиний API.
  * **Власні енергоефективні процесори:** Впровадження серверних процесорів **AWS Graviton4** та спеціалізованих чипів для навчання ШІ **Trainium2** і **Inferentia2**, що знижують вартість обчислень до 40%.
  * **Serverless-еволюція:** Розвиток концепції бессерверних баз даних (Amazon Aurora Serverless v2, DynamoDB Global Tables) та подійного обчислення (AWS Lambda).

* **Microsoft Azure:**
  * **Альянс з OpenAI та Azure OpenAI Service:** Пряма інтеграція моделей GPT-4o та DALL-E у хмарну інфраструктуру Azure, що дозволило створити суперекосистему **Microsoft Copilot**.
  * **Гібридні хмари та Edge Computing:** Розвиток платформи **Azure Arc**, яка дозволяє управляти мультихмарними та локальними дата-центрами через єдину консоль Azure.
  * **Конфіденційні обчислення (Confidential Computing):** Впровадження апаратного шифрування оперативної пам'яті віртуальних машин на базі AMD SEV-SNP та Intel TDX.

* **Google Cloud Platform (GCP):**
  * **Екосистема Gemini та Vertex AI:** Створення уніфікованої ШІ-платформи **Vertex AI** та інтеграція мультимодальної моделі **Gemini 1.5 Pro** для корпоративного аналізу даних.
  * **Спеціалізовані тензорні процесори (TPU v5p):** Розробка нових поколінь прискорювачів для навчання надвеликих нейромереж.
  * **Кліматично нейтральні хмари (Green Cloud):** Впровадження інструментів Carbon Footprint та інтелектуального вибору регіонів із найвищою часткою відновлюваної енергетики.

<span>5. Здійсніть огляд інтернет джерел та визначте топ-5 українських постачальників хмарних послуг у 2023-2025 роках та дослідіть їх можливості.</span>

<blockquote>

1. **GigaCloud (Лідер ринку):**
   * *Можливості:* Надає IaaS-рішення на базі VMware та OpenStack, спеціалізовані хмари для банку (PCI DSS) та держави (КСЗІ). Має дата-центри в Україні (Київ, Львів) та ЄС (Варшава, Франкфурт).
   * *Особливості:* Висока відмовостійкість, підтримка 24/7/365, послуга аварійного відновлення (DRaaS).

2. **DeNovo:**
   * *Можливості:* Один із перших професійних хмарних провайдерів України. Пропонує приватні та публічні хмари, захищені хмари відповідно до вимог ДСТЗІ, а також власну систему бекапу та катастрофостійкості.
   * *Особливості:* Орієнтація на корпоративний сектор, банківські установи та державний сегмент.

3. **UCloud:**
   * *Можливості:* Спеціалізується на побудові гібридних та катастрофостійких хмарних рішень. Має майданчики в Україні, Польщі, Німеччині та Нідерландах.
   * *Особливості:* Безкоштовне мігрування ресурсів, прямі канали зв'язку між дата-центрами України та Європи.

4. **Tucha (Туча):**
   * *Можливості:* Перший український провайдер хмарних сервісів (з 2006 року). Пропонує віртуальні сервери (TuchaHosting, TuchaFlex), хмарний офіс та рішення для автоматизації бізнесу.
   * *Особливості:* Гнучка конфігурація ресурсів, орієнтація на малий та середній бізнес (SMB), високий рівень техпідтримки.

5. **TetCloud:**
   * *Можливості:* Український провайдер, що пропонує послуги VDS/VPS, виділені сервери та хмарні сховища з розташуванням обладнання в Україні та Європі.
   * *Особливості:* Доступна цінова політика, швидке розгортання ресурсів, захист від DDoS-атак.

</blockquote>

<span>7. Уявіть ситуацію, що Вам для реалізації робочого завдання необхідно розгорнути власний хмарний сервер. Яку б світову та українську платформу ви обрали б. Поясніть чому.</span>

<blockquote>

* **Світова платформа — Amazon Web Services (AWS):**
  * AWS є світовим стандартом у сфері IaaS/PaaS. Якщо робоче завдання вимагає високої масштабованості, використання сервісів машинного навчання (AWS Bedrock), керованих баз даних (Amazon Aurora) або розгортання глобальних мікросервісних додатків — AWS надає найбагатший інструментарій (понад 200 сервісів). Крім того, наявність програми AWS Free Tier дозволяє безкоштовно протестувати інфраструктуру на початковому етапі.

* **Українська платформа — GigaCloud:**
  * Для розгортання сервера у сфері українського бізнесу чи державного сектору GigaCloud є оптимальним вибором за рахунок:
    1. **Дотримання законодавства:** Наявність атестата КСЗІ (захист персональних даних) та сертифіката PCI DSS.
    2. **Низької затримки (Ping):** Розташування дата-центрів у Києві та Львові забезпечує мінімальний отклик для українських користувачів.
    3. **Фінансової стабільності:** Розрахунки у гривні захищають від курсових коливань валют.
    4. **Захисту від ризиків війни:** Можливість резервування даних на майданчиках у Польщі (Варшава).

</blockquote>
