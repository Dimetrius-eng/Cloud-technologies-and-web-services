<blockquote>

**2.1. Для чого потрібні AMIs? Чим відрізняються приватні та публічні AMIs?**<br>

**AMI (Amazon Machine Image)** – це попередньо сконфігурований шаблон (образ) операційної системи та програмного забезпечення, необхідний для швидкого створення та запуску віртуальної машини (EC2-інстансу). Розрізняють публічні (Public) та приватні (Private) AMIs.
*   **Публічні AMIs** – загальнодоступні образи, які надаються компанією AWS (наприклад, Ubuntu, Amazon Linux, Windows Server) або незалежними розробниками через AWS Marketplace.
*   **Приватні AMIs** – власні кастомні образи, створені користувачем на основі налаштованого інстансу для внутрішнього використання в організації або поширення між конкретними AWS-акаунтами.

---
<br>

**2.2. Для чого потрібні EBS? Які типи EBS підтримуються в AWS?**<br>  

**Amazon EBS (Elastic Block Store):** – це високопродуктивне блокове сховище, яке підключається до EC2-інстансів як віртуальний жорсткий диск (дисковий накопичувач). Дані на EBS зберігаються незалежно від життя самого інстансу.<br>    

**Основні типи EBS:**  

1.  **General Purpose SSD (gp2 / gp3)** – універсальні SSD-диски з оптимальним балансом ціни та продуктивності для більшості робочих навантажень.  
2.  **Provisioned IOPS SSD (io1 / io2 / io2 Block Express)** – високопродуктивні SSD з гарантованою пропускною здатністю для критичних баз даних (PostgreSQL, Oracle).  
3.  **Throughput Optimized HDD (st1)** – недорогі магнітні диски для великих обсягів даних із послідовним доступом (Big Data, логи).  
4.  **Cold HDD (sc1)** – найдешевші диски для реліктових даних із рідким доступом.

---
<br>

**2.3. Для чого використовуються Snapshots?**<br>  

**EBS Snapshots** — це точкові резервні копії (point-in-time backups) блокових дисків EBS, які автоматично зберігаються в об'єктному сховищі Amazon S3. Вони є інкрементними (зберігають тільки зміни після попереднього снапшоту) та 
використовуються для розгортання нових дисків, відновлення після збоїв або міграції ресурсів між регіонами.

---
<br>

**2.4. Перерахуйте які основні типи інстансів є в AWS? Коли доцільно використовувати кожен з них?**<br>  

*   **General Purpose (Загального призначення - t2, t3, m5)** – збалансовані за процесорною потужністю та пам'яттю. Використовуються для веб-серверів, середовищ розробки та невеликих баз даних.
*   **Compute Optimized (Обчислювально оптимізовані - c5, c6g)** – висока потужність CPU для обробки коду, медіа-кодування та ігрових серверів.
*   **Memory Optimized (Оптимізовані за пам'яттю - r5, x2gd)** – великий обсяг RAM для In-Memory баз даних (Redis, RAM-кеш) та аналітики даних.
*   **Storage Optimized (Оптимізовані за дисковою системою - i3, d2)** – прямий доступ до високошвидкісних NVMe SSD для високонавантажених NoSQL баз даних.
*   **Accelerated Computing (Прискорені обчислення - g4dn, p3)** – оснащені GPU для машинного навчання (AI/ML), нейромереж та 3D-рендерингу.

### Відповіді на контрольні питання

**<span>1. Яку роль відіграє Key Pair при підключенні до EC2-інстансу?</span>**<br>

**Key Pair (пара криптографічних ключів)** забезпечує захист підключення на основі асиметричного шифрування. Публічний ключ автоматично імпортується AWS на віртуальну машину, а приватний ключ (`.pem` / `.ppk`) зберігається на комп'ютері користувача. Він використовується для автентифікації при SSH-підключенні до Linux або для безпечної розшифровки пароля адміністратора Windows-інстансу.

<br>

**<span>2. Яка команда використовується для підключення до EC2-інстансу через SSH?</span>**<br>

Стандартна команда у терміналі:

    ```bash
    
    ssh -i "path/to/private_key.pem" username@public_ip_address
    
    ```
    
*Приклад:* `ssh -i "linux_key.pem" ubuntu@3.121.42.105`

<br>

**<span>3. Як можна підключитися до Linux-інстансу AWS EC2?</span>**<br>

1.  **SSH-клієнт у терміналі:** Використання OpenSSH, PuTTY або MobaXterm з приватним ключем `.pem`.
2.  **EC2 Instance Connect:** Пряме підключення через веб-браузер з консолі AWS без додаткового ПЗ.
3.  **AWS Systems Manager (Session Manager):** Захищене підключення через консоль або CLI без відкриття порту 22 у Security Group.

<br>

**<span>4. Як можна підключитися до Windows-інстансу AWS EC2?</span>**<br>

1.  **Remote Desktop Protocol (RDP):** За допомогою стандартної програми «Підключення до віддаленого робочого столу» (RDP) у Windows або Microsoft Remote Desktop на macOS/Linux (попередньо розшифрувавши пароль `Administrator` за допомогою `.pem` ключа).
2.  **Fleet Manager / Systems Manager:** Графічне підключення через браузер у консолі AWS.

<br>

**<span>5. У чому відмінність між станами Stop і Terminate для EC2-інстансу?</span>**<br>

*   **Stop (Зупинка):** Віртуальна машина вимикається (як звичайний ПК). Обчислювальні ресурси (vCPU/RAM) вивільняються, плата за години роботи EC2 припиняється, але прив'язаний диск EBS та всі дані на ньому зберігаються. Інстанс можна запустити знову у будь-який момент.
*   **Terminate (Видалення):** Віртуальна машина остаточно видаляється з акаунта AWS без можливості відновлення. Всі системні диски EBS знищуються, а ресурси повністю вивільняються.
